Privacy Policy

AWS QuickAssist is a browser extension designed to improve the AWS Console experience, particularly when working with CloudWatch Logs.

Your privacy is important to us. This Privacy Policy explains what information the extension collects and how it is used.

Information We Collect

AWS QuickAssist does not collect, store, or transmit any personal information.

The extension does not collect:

  • Personal information (name, email, address, etc.)
  • AWS account data
  • CloudWatch log data
  • Browsing history
  • Authentication credentials

Local Storage

The extension may store small configuration preferences locally in your browser using Chrome's storage API. These settings are used only to remember user preferences (such as log highlighting or filtering options).

This data:

  • Stays only in your browser
  • Is never transmitted to any server
  • Can be removed by uninstalling the extension

Third-Party Services

AWS QuickAssist does not use analytics services, advertising services, or third-party trackers.

Permissions

The extension only uses permissions required to modify the AWS Console interface to provide features like log filtering, highlighting, and navigation improvements.

These permissions are used solely for the functionality of the extension.

Changes to This Policy

This Privacy Policy may be updated if new features are added to the extension. Any updates will be reflected on this page.

Contact

If you have any questions regarding this Privacy Policy, you may contact the developer.
